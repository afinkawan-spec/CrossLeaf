# CrossLeaf 1.0.0

First public CrossLeaf build, based on CrossPoint Reader 1.6.5.

- CrossLeaf boot and sleep logos, oriented for portrait use.
- Two-cover recent-books home layout.
- Simplified Settings and in-reader menus with the selected fixed defaults.
- Reader progress and battery bars, with independent thickness controls.
- Reading button behavior and Game Book Mode changes carried forward from the
  tested CrossLeaf source.
- Dictionary selection and lookup retained.
- Release firmware attached to this GitHub Release; no firmware image is stored
  in the Git repository.
