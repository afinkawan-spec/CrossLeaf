# CrossLeaf

CrossLeaf is a personal Xteink X4 firmware based on CrossPoint Reader 1.6.5.
This 1.0.0 release packages the reader configuration and interface changes
described in [CHANGELOG.md](CHANGELOG.md).

The complete source is kept here for inspection and rebuilding. The ready-to-
flash firmware is published as a GitHub Release asset, not stored in Git history.

## Build

See [BUILDING.md](BUILDING.md) for the tested Windows build setup and command.

## Branding

The CrossLeaf boot and sleep artwork is in `branding/` and in the firmware's
`src/images/` assets. The standalone logo is provided as a 120 x 120 PNG.

## Upstream

CrossLeaf is derived from [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader).
The inherited source retains some upstream internal names and documentation.
See [LICENSE](LICENSE) and the vendored FreeInk SDK notices for licensing.
